# NOTILE Task Manager

Crie uma aplicação web chamada NOTILE Task Manager.



Quero um sistema simples, moderno e profissional para gerenciamento de tarefas pessoais.



Funcionalidades:



1. Dashboard inicial mostrando:

   

   - Total de tarefas.

   - Tarefas pendentes.

   - Tarefas concluídas.



2. Cadastro de tarefas:

   

   - Título.

   - Descrição.

   - Data de vencimento.

   - Prioridade: baixa, média ou alta.



3. Listagem de tarefas:

   

   - Exibir todas as tarefas.

   - Permitir marcar como concluída.

   - Permitir excluir tarefas.

   - Permitir filtrar entre todas, pendentes e concluídas.



4. Design:

   

   - Identidade visual da NOTILE.

   - Fundo claro.

   - Azul escuro como cor principal.

   - Interface responsiva.

   - Menu lateral e dashboard organizado.



Utilize React e TypeScript.



Inicialmente, armazene os dados no próprio navegador utilizando localStorage, sem necessidade de banco de dados.



Todos os botões devem funcionar de verdade.



Crie a aplicação completa e apresente uma interface funcional, não apenas uma imagem ilustrativa.
